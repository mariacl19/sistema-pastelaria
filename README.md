# Sistema de Gerenciamento de Pedidos – Pastelaria da Marli

## Sobre o projeto

Este projeto foi desenvolvido como parte da atividade de curricularização da extensão do curso de Tecnologia em Análise e Desenvolvimento de Sistemas do IFSP – Campus Bragança Paulista.

O sistema tem como objetivo auxiliar na organização dos pedidos e produtos da Pastelaria da Marli, buscando melhorar o atendimento, reduzir erros e otimizar os processos do estabelecimento.

A ideia surgiu da necessidade de substituir parte dos processos manuais, como anotações de pedidos em papel e cálculos feitos manualmente.

## Objetivos

- Organizar os produtos e seus respectivos preços.
- Facilitar o registro de novos pedidos.
- Melhorar a comunicação e o acompanhamento dos pedidos pela cozinha.
- Automatizar tarefas e reduzir erros.
- Contribuir para um atendimento mais organizado e eficiente.

## Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e organização visual.
- **JavaScript:** funcionalidades e interações do sistema.
- **GitHub:** armazenamento e compartilhamento do código.
- **Netlify:** publicação do site.

## Funcionalidades

O protótipo conta com as seguintes funcionalidades:

- **Início:** página inicial do sistema.
- **Novo Pedido:** área destinada ao registro de pedidos.
- **Pedidos da Cozinha:** acompanhamento dos pedidos.
- **Produtos:** cadastro, edição, exclusão e pesquisa de produtos.
- **Imagens dos produtos:** possibilidade de selecionar e exibir imagens.
- **Geração de PDF:** funcionalidade para gerar documentos com os produtos cadastrados.

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `login.html` ou a página inicial disponível no projeto pelo navegador.
4. Navegue pelas opções do menu para acessar as funcionalidades.

## Desenvolvimento

O projeto está em desenvolvimento e esta versão representa um protótipo inicial, criado para organizar e apresentar as principais funcionalidades do sistema.

Futuramente, pretende-se ampliar o projeto utilizando novas tecnologias, como React e MySQL, para aprimorar o gerenciamento dos produtos e pedidos.
